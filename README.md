# 텍스트 정리 도구

줄바꿈이 제멋대로 끊긴 소설 텍스트(txt)를 읽기 좋은 문단으로 정리해 주는 무료 웹 도구입니다.

**👉 바로 사용하기: https://jin524320.github.io/text-cleaner/**

설치도 회원가입도 필요 없습니다. 글은 서버로 전송되지 않고 **내 브라우저 안에서만** 처리됩니다.

## 사용 방법

1. 위 주소를 엽니다.
2. 파일을 열거나(끌어다 놓기도 가능) 글을 직접 붙여넣습니다. 글자가 깨져 보이면 인코딩(UTF-8, EUC-KR/CP949 등)을 바꿔 보세요.
3. **처리하기**를 누릅니다.
4. 오른쪽 결과를 확인하고 **저장**합니다.

**리셋**은 글과 파일만 지웁니다. 설정은 그대로 유지됩니다.

## 자동으로 해 주는 일

- 중간에 끊긴 줄을 이어서 문단으로 합칩니다.
- 대사(따옴표)는 따로 문단으로 나눕니다.
- 제목, 구분선(`***`, `---`), `[시스템 메시지]` 같은 줄은 다른 줄과 합치지 않습니다.
- 불필요한 공백과 빈 줄을 정리합니다.

## 설정 (설정 버튼)

변경하면 바로 이 브라우저에 저장됩니다. 결과에 반영하려면 **처리하기**를 다시 눌러 주세요.

- 공백 정리, 문장부호 앞뒤 간격 보정
- 짧은 줄을 제목으로 인식
- 문단 첫 줄 들여쓰기
- 말줄임표(`...` → `…`) 통일
- 따옴표 모양 통일
- 낱말 중간에서 끊긴 줄 복원 (글자 수 기준으로 자동 줄바꿈된 파일용)
- 문장부호 바로잡기 (모두 기본 꺼짐, 글자는 건드리지 않고 문장부호의 모양만 고침)
  - 전각 쉼표(`，`) → 일반 쉼표(`,`)
  - 대사 끝에 잘못 찍힌 여는 따옴표(`.“`) → 닫는 따옴표(`.”`)
  - 한 줄 안에서 전각/반각이 섞인 괄호(`［…]`) → 짝 맞추기
  - 고친 곳은 처리 후 **고친 곳 보기**에서 목록으로 확인할 수 있습니다. 원본 칸은 바뀌지 않습니다.
- 제목 앞에 `## ` 붙이기 (기본 꺼짐, 마크다운을 읽는 뷰어·변환기용)
  - `1화`, `제2장`, `Chapter 3`, `EP.4`, `프롤로그`, `<-- 서장 -->`, `1화. 시작`처럼 **확실한 제목**에만 붙습니다.
  - 짧은 줄을 제목으로 추측한 줄이나 `제목: ○○` 형태에는 붙이지 않습니다. 이미 `## `가 있으면 또 붙이지 않습니다.
- 긴 문단 나누기 (기본 꺼짐, 문단 모양만 바뀌고 글자는 그대로)
  - 설명 문단이 기준 글자 수(기본 300자, 설정에서 100~2000자로 변경)보다 길면 문장 끝(`.` `?` `!` `…`)에서 여러 문단으로 나눕니다.
  - 대사(따옴표로 시작하는 문단), 제목, 구분선은 나누지 않고, 따옴표·괄호 안의 마침표에서도 나누지 않습니다. 문장 끝을 찾지 못하면 그대로 둡니다.
  - 나눈 곳은 처리 후 **고친 곳 보기**에서 확인할 수 있습니다.

## 결과에서 글자 찾기

화면 오른쪽 아래 **찾기**로 결과 칸(또는 원본 칸) 안에서 글자를 찾을 수 있습니다.

- 글자를 쓰고 **Enter**(또는 ▼)를 누르면 다음 곳으로, **Shift+Enter**(또는 ▲)는 이전 곳으로 이동하며 몇 번째/전체 몇 곳인지 표시됩니다. 대소문자는 구분하지 않습니다.
- "결과에서 / 원본에서"를 바꿔 같은 글을 두 칸에서 찾으면 **어디가 어떻게 고쳐졌는지** 비교할 수 있습니다.
- 아주 긴 글(수백만 자)은 처음 한 번 이동할 때 위치를 계산하느라 몇 초 걸릴 수 있습니다.

## 노란 경고가 나오면

따옴표나 괄호가 닫히지 않은 채 줄이 합쳐진 곳입니다. 대부분 원본의 따옴표 오타입니다.

1. **자세히 보기**를 누르면 위치와 내용이 나옵니다.
2. **이동** 버튼을 누르면 원본 칸의 그 줄로 바로 갑니다.
3. 원본에서 고친 뒤 다시 처리하세요.

## 알아두실 점

- 원본 글자는 지우지 않고, 공백과 줄바꿈만 정리합니다. (위의 문장부호 바로잡기·제목 `## ` 붙이기·긴 문단 나누기를 켠 경우에만 해당 부분이 바뀝니다. 긴 문단 나누기는 글자는 그대로이고 문단 나눔만 달라집니다.)
- 설정은 사용 중인 **브라우저에 저장**됩니다. 다른 컴퓨터나 다른 브라우저에서는 다시 설정해야 합니다.
- 처리한 결과를 다시 원본 칸에 넣어 한 번 더 처리하면, 원본에 따옴표 오타가 있는 몇 줄이 달라질 수 있습니다. 원본 파일을 한 번만 처리하는 것이 안전합니다.
- 매우 긴 글(수백만 자)도 보통 몇 초 안에 처리되지만, 컴퓨터나 휴대폰 사양에 따라 느릴 수 있습니다.
