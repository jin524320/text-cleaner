# 텍스트 정리 도구

줄바꿈이 제멋대로 끊긴 소설 텍스트(txt)를 읽기 좋은 문단으로 정리해 주는 무료 웹 도구입니다.

**👉 바로 사용하기: https://jin524320.github.io/text-cleaner/**

설치도 회원가입도 필요 없습니다. 글은 서버로 전송되지 않고 **내 브라우저 안에서만** 처리됩니다.

## 사용 방법

1. 위 주소를 엽니다.
2. 파일을 열거나(끌어다 놓기도 가능) 글을 직접 붙여넣습니다. 글자가 깨져 보이면 인코딩(UTF-8, EUC-KR/CP949 등)을 바꿔 보세요.
3. **처리하기**를 누릅니다. (원본 칸에서 `Ctrl+Enter`도 됩니다.)
4. 오른쪽 결과를 확인하고 **저장** 또는 **복사**합니다.

**리셋**은 글과 파일만 지웁니다. 설정은 그대로 유지됩니다.

**앱처럼 설치하기** — 페이지 아래의 **앱으로 설치** 버튼(크롬·엣지는 주소창 오른쪽 설치 아이콘도 가능)을 누르면 바탕화면·시작 메뉴에서 바로 열 수 있습니다. 아이폰·아이패드는 공유 버튼 → **홈 화면에 추가**. 한 번 열어 본 뒤에는 인터넷이 없어도 열립니다.

## 기본으로 해 주는 일

- 중간에 끊긴 줄을 이어서 문단으로 합칩니다.
- 대사(따옴표)는 따로 문단으로 나눕니다.
- 제목, 구분선(`***`, `---`), `[시스템 메시지]` 같은 줄은 다른 줄과 합치지 않습니다.
- 불필요한 공백과 빈 줄을 정리합니다.
- 일정 글자 수마다 줄이 꺾이고 줄 사이마다 빈 줄이 낀 글은 자동으로 알아보고 이어 붙입니다. (아래 [줄 꺾인 글](#줄-꺾인-글) 참고)

## 설정 (설정 버튼)

변경하면 바로 이 브라우저에 저장됩니다. 결과에 반영하려면 **처리하기**를 다시 눌러 주세요. 표에 "꺼짐"이라고 적은 것만 직접 켜면 됩니다.

| 설정 | 하는 일 | 기본 |
|---|---|---|
| 공백 정리 · 문장부호 앞뒤 간격 | 연속 공백, 줄 끝 공백, `. ? !` 앞뒤 간격을 보정 | 켜짐 |
| 짧은 줄을 제목으로 인식 | 20자 이하이면서 문장부호 없이 끝나는 줄을 제목으로 보고 합치지 않음 | 꺼짐 |
| 문단 첫 줄 들여쓰기 | 모든 문단 앞에 전각 공백 1칸 | 꺼짐 |
| 말줄임표 통일 | `...` → `…` | 꺼짐 |
| 따옴표 통일 | 둥근 따옴표 → 곧은 따옴표 | 꺼짐 |
| 낱말 중간 줄바꿈 복원 | 공백 없이 끊긴 줄을 띄어쓰기 없이 붙임 (글자 수 기준으로 자동 줄바꿈된 파일용. 원래 공백이 없는 글에는 켜지 마세요) | 꺼짐 |
| 줄 끝 보이지 않는 글자 지우기 | 마침표 뒤처럼 줄 끝에 붙은 눈에 안 보이는 글자(너비 0 공백 등) 때문에 문장 끝으로 인식되지 않을 때 켬. 줄 중간은 그대로 | 꺼짐 |
| 문장부호 바로잡기 | 전각 쉼표 `，`→`,`, 대사 끝의 잘못된 여는 따옴표 `.“`→`.”`, 섞인 괄호 짝 맞추기. 고친 곳은 처리 후 **고친 곳 보기**에서 확인 | 꺼짐 |
| 제목 앞에 `## ` 붙이기 | `1화`, `제2장`, `Chapter 3`, `프롤로그`처럼 **확실한 제목**에만 마크다운 제목 표시를 붙임 (뷰어·변환기용) | 꺼짐 |
| 구분선 모양 통일 | `***`, `---`, `====` 등 장식 기호 3개 이상인 줄을 고른 모양 하나로 맞춤 (`***`, `* * *`, `---`, `===`, `~~~`, `◆ ◆ ◆`) | 꺼짐 |
| 제목 앞 빈 줄 늘리기 | 확실한 제목 앞에 빈 줄을 한 줄 더 넣어 화가 바뀌는 곳을 눈에 띄게 함 | 꺼짐 |
| 긴 문단 나누기 | 기준 글자 수(기본 300자, 100~2000자)보다 긴 설명 문단을 문장 끝에서 나눔. 대사·제목·구분선, 따옴표·괄호 안은 나누지 않음 | 꺼짐 |
| 줄 꺾인 글 처리 | 자동 판정 / 항상 켜기 / 끄기 | 자동 |

### 설정 묶음

자주 쓰는 설정을 이름 붙여 저장해 두고 한 번에 불러올 수 있습니다. (예: "스캔 글용", "일반 글용")

- 설정 창 맨 위에서 **지금 설정 저장**(최대 20개, 이름 20자까지, 같은 이름은 덮어씀) → **불러오기** / **지우기**.
- 다른 컴퓨터·브라우저로 옮기려면 **파일로 내보내기**(`설정묶음.txt`) → 거기서 **파일에서 가져오기**.

## 결과에서 글자 찾기

화면 오른쪽 아래 **찾기**에 글자를 쓰고 **Enter**(▼)를 누르면 다음 곳으로, **Shift+Enter**(▲)는 이전 곳으로 이동합니다. "결과에서 / 원본에서"를 바꿔 같은 글을 두 칸에서 찾으면 어디가 어떻게 고쳐졌는지 비교할 수 있습니다. 아주 긴 글(수백만 자)은 처음 한 번 이동할 때 몇 초 걸릴 수 있습니다.

## 노란 경고가 나오면

따옴표나 괄호가 닫히지 않은 채 줄이 합쳐진 곳입니다. 대부분 원본의 따옴표 오타입니다.

1. **자세히 보기**를 누르면 위치와 내용이 나옵니다. 목록은 복사·저장할 수 있습니다.
2. **이동** 버튼을 누르면 원본 칸의 그 줄로 바로 갑니다.
3. 원본에서 고친 뒤 다시 처리하세요.

스캔한 글(OCR)은 닫는 따옴표 `」`가 `J`, `1`, `)`, `?.` 같은 글자로 잘못 읽히는 일이 많습니다. 그런 줄은 경고 아래에 `OCR 오타 의심 — 원본 120번째 줄 끝 '? J'`처럼 노란 글씨로 알려 주고, **의심 줄** 버튼으로 바로 갈 수 있습니다. 설명만 덧붙이며 글자는 고치지 않습니다.

## 줄 꺾인 글

일정 글자 수마다 줄이 꺾이고 **줄 사이마다 빈 줄이 하나씩** 낀 글이 있습니다. 예: `숨긴 무` / (빈 줄) / `림 고수였다`. 이런 글은 빈 줄을 무시하고 이어 붙여야 읽기 좋습니다.

- **자동 판정(기본)**: 그런 글로 보이는 경우에만 적용하고, 상태 표시줄에 "줄 꺾인 글로 판단"이라고 알려 줍니다.
- 30줄 미만의 짧은 글이나 자동으로 안 잡히는 글은 설정에서 **항상 켜기**로 바꾸세요. 평범한 글에 켜면 문단 구분이 사라집니다.

## 알아두실 점

- 기본 설정에서는 원본 글자를 지우지 않고 공백과 줄바꿈만 정리합니다. 문장부호 바로잡기, 제목 `## ` 붙이기, 구분선·말줄임표·따옴표 통일, 줄 끝 보이지 않는 글자 지우기를 켜면 해당 부분이 바뀝니다.
- 설정과 설정 묶음은 사용 중인 **브라우저에 저장**됩니다. 다른 컴퓨터·브라우저에서는 다시 설정하거나 묶음을 내보내 옮기세요.
- 처리한 결과를 다시 원본 칸에 넣어 한 번 더 처리하면, 원본에 따옴표 오타가 있는 몇 줄이 달라질 수 있습니다. 원본 파일은 한 번만 처리하는 것이 안전합니다.
- 매우 긴 글(수백만 자)도 보통 몇 초 안에 처리되지만, 컴퓨터나 휴대폰 사양에 따라 느릴 수 있습니다.
